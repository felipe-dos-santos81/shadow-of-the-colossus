# S13 Phaedra Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the shared colossus systems — the exporter for all 16, a generic control-def evaluator and shared predicate library, the additive motion layer, routes from `.path`, terrain classes from `.clb`, a coverage report — and prove them on Phaedra (`KIRIN`, `kirin_a`, `arena_04`), with Gaius's S12 outputs unchanged.

**Architecture:** Stdlib-Python exporters write derived JSON into the library (`behaviour/<BOSS>.graph.json` gaining additive `/0` keys, `behaviour/<stem>.route.json`, `stage/<arena>.terrain.json`); pure C++ modules consume them (`scr_cdef`, `scr_library`, `additive`, `route`, `terrain`); Phaedra is an encounter table plus a thin glue file on the shared step. One contracts task creates every new file, target and interface; six lanes then run in parallel git worktrees; wiring, proof and acceptance run serially.

**Tech Stack:** C++20, SDL3/SDL_GPU/Metal, doctest, .NET 10 + xUnit (BpConvert), Python 3 stdlib, bash 3.2.

**Spec:** `docs/superpowers/specs/2026-10-24-s13-phaedra-systems-design.md` — its §13 builder-check rulings are binding and override §§1–12 where they differ. Recon (read the relevant one per task): `.superpowers/sdd/2026-10-23-s13-recon/{graph,kirin,arena04,additive,census16,path,clb}/findings.md` and their `py/` scripts.

- No committed derived game data except small generated numeric headers on the `quadratus_root.h`/`knight_root.h` precedent: graphs, routes, terrain JSON, sidecars and fixtures go to the library or the build directory.
- Windowed; the cursor is never captured. `caffeinate -dimsu` around every viewer/verify/acceptance run; **GPU runs serial across all lanes**; never two runs sharing an `out/`.
- Bash 3.2; stdlib Python (`python3 -I`); C++20; no new dependency; the game tree read-only; the converter's parsing stays behind its readers.

- Every authored value carries a label (`authored`, `data <VA|path>`, `measured`, `binary <VA>`, `guess`) in a comment; the results note tabulates provenance.
- `make verify` after every task (per-task gate); `make verify-long` before the merge.
