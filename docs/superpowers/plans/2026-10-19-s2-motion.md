# S2 "It moves" — Real .anb Playback + Locomotion — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The SDL viewer plays Wander's real decoded clips — standing, walking, running, selected by the controller — plus Agro's kick, all baked into their glbs as glTF animation tracks and accepted against the capture set.

**Architecture:** The converter gains an `Anim/` module (flag-clear `.anb` reader, sibling `.skb` bank reader, track→joint map) and the glTF writer emits rotation/translation animation channels (bridge applied, statics included, times at `rate × 30`, `matrix`→TRS for animated joints). The app plays real clips by default, selects stand/walk/run from the S3 controller state, and skips the ground lift when a clip carries the root series.

**Tech Stack:** .NET 10 / xUnit / SharpGLTF (converter); C++20 / SDL3 / cgltf / doctest / ctest (app).

**Spec:** `docs/superpowers/specs/2026-10-19-s2-motion-design.md`

## Global Constraints

- SDL runtime; windowed; the cursor is never captured.
- Clips live in the model's glb (D-S7) — no sidecar format.
- Clips play in place: the root series' horizontal components are zeroed; the controller owns position.
- The S3 ground lift applies only when the active model has no root-carrying clip.
- The horse (`agro.glb`) is checked standalone; the arena stays Wander-only; flag-set/camera clips deferred.
- Offline-first: the runtime never parses `.anb`/`.skb`; all decode is converter-side.
- Apple Silicon; GPL-3.0 — no game assets or derived glbs committed.
- Tests that need the game tree fail fast when `SOTC_GAME_ROOT` is unset (never skip silently).
- Verification: `dotnet test tests/BpConvert.Tests -v q`; `ctest --test-dir app/build --output-on-failure`.
- Typed commits (`feat:`, `fix:`, `test:`, `docs:`, `chore:`).

## Review Focus

- **Wrong rate/fps → wrong motion speed.** Pinned by Task 1 (stand = 76 frames, rate 0.5, fps 15) and Task 3 (duration 5.0 s).
- **Dropped static tracks → straight-fingered T-pose hands.** Pinned by Task 1 (10 statics) and Task 3 (static rotation channels are emitted).
- **Loop discontinuity → a snap at the wrap.** Pinned by Task 3 (first key == last key on stand/walk/run loops).
- **`matrix` on an animated joint → non-conformant glb.** Pinned by Task 3 (animated joints carry TRS, no `matrix`).
- **Floating/sinking with a clip active.** Pinned by Task 6 (the lift rule) and Task 7 (the arena stills).

  ```csharp
  namespace BpConvert.Core.Anim;

  public sealed class AnimClip {
      public required string Name { get; init; }        // file stem, e.g. "player_a_stand"
      public required int Frames { get; init; }
      public required double Rate { get; init; }       // the clip's Q12 field, default 1.0

      public required List<AnimTrack> Tracks { get; init; }

      public required bool IsStatic { get; init; }     // type 0: one unit quaternion, no keys
      public required List<System.Numerics.Quaternion> Keys { get; init; } // game convention (raw)
  }

  public static class AnbReader { public static AnimClip Read(string path); }
  ```
